## English

### 📱 Project Description
This is a passion project built entirely on an **Android Tablet** using **Sketchware**. It’s a dedicated companion app for Warframe players, featuring a real-time Dashboard and a massive Codex.

### ✨ Key Features
* **Real-time WorldState:** Tracking Fomorian/Razorback, Plains cycles, and Fissures via the Warframestat API.
* **The Codex (Index 4):** A complete database for Mods, Relics, Arcanes, and Gear.
* **Smart Links:** Direct integration with Warframe Market and the Wiki.
* **Custom Themes:** Dynamic UI inspired by Grineer, Corpus, and Orokin factions.

### 🛠 Technical Info
* **Built on:** Android Tablet 📱
* **Tools used:** Sketchware, HTML5, CSS3, JavaScript.
* **Data Sources:** [WFCD Warframestat API](https://api.warframestat.us) & [Warframe Drop Data](https://github.com/WFCD/warframe-drop-data).

> **Note on APK:** This project was originally designed as an APK for private use. I am sharing the source code here to be transparent with the community and follow security guidelines.

## Français

### 📱 Description du projet
C'est un projet passionné développé entièrement sur une **tablette Android** avec **Sketchware**. Il s'agit d'une application compagnon pour les joueurs de Warframe, comprenant un tableau de bord en temps réel et un Codex massif.

### ✨ Fonctionnalités clés
* **WorldState en temps réel :** Suivi des Fomoriens/Razorbacks, des cycles des Plaines et des Fissures via l'API Warframestat.
* **Le Codex (Index 4) :** Une base de données complète pour les Mods, Reliques, Arcanes et l'équipement.
* **Liens intelligents :** Intégration directe avec Warframe Market et le Wiki.
* **Thèmes personnalisés :** Interface dynamique inspirée des factions Grineer, Corpus et Orokin.

### 🛠 Infos techniques
* **Développé sur :** Tablette Android 📱
* **Outils :** Sketchware, HTML5, CSS3, JavaScript.
* **Sources des données :** [WFCD Warframestat API](https://api.warframestat.us) et [Warframe Drop Data](https://github.com/WFCD/warframe-drop-data).

> **Note sur l'APK :** Ce projet a été initialement conçu comme une APK pour un usage privé. Je partage le code source ici par souci de transparence avec la communauté et pour respecter les règles de sécurité.
